<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| PATH/cwd → candidate enumeration | Untrusted directories and relative/empty entries determine executable candidates. |
| Candidate metadata → ownership classification | Foreign files, symlinks, and forged markers attempt to spoof this package. |
| Inspection evidence → terminal/JSON | Hostile paths/errors can inject terminal controls or leak unstable data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-14 | Spoofing | `src/core/doctor.ts` ownership | high | mitigate | Require realpath agreement plus validated package marker; same-name executable alone is collision. |
| T-01-15 | Elevation of Privilege | candidate inspection | high | mitigate | No execution/body open/shell/package operation; execution-sentinel and deny-spy tests. |
| T-01-16 | Tampering | collision remediation | high | mitigate | Doctor exposes no write/install/unlink/rename/PATH API and hashes all sentinels before/after repeats/parallel runs. |
| T-01-17 | Information Disclosure | human diagnostics | medium | mitigate | Sanitize terminal controls and report only safely resolved metadata; structured JSON remains schema-bounded. |
| T-01-18 | Denial of Service | symlink/large PATH matrix | medium | mitigate | Bounded per-entry inspection with error-as-data; no recursive traversal. |
</threat_model>
