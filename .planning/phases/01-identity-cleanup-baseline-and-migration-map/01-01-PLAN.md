## Phase Goal

**As an** operator or maintainer, **I want to** use one collision-safe MLX product surface and inspect an honest validation baseline plus complete replacement map, **so that** I can operate and evolve the brownfield system without ambiguous identity, unsafe takeover, or false acceptance.

<objective>
Create the walking CLI skeleton: a side-effect-free process entry, the complete typed command tree, deterministic help and parsing, explicit later-phase unavailability, and isolated human/JSON rendering.

Purpose: Give every later Phase 1 slice one stable user-facing route and prove the hardest constraint first: invoking a documented shell cannot accidentally load or run the legacy application.
Output: Pre-edit dirty-worktree evidence, a fail-first command harness, public-process tests, and focused CLI contract modules that make bare help, unavailable leaves, parse errors, and JSON mode executable end to end.
</objective>

## Scope Justification

This plan owns 12 paths across three strictly ordered TDD tasks because the first path must capture immutable operator state before any Phase 1 edit, and the same public-process RED contract must then drive the entry/catalog/orchestrator/renderers through GREEN before their shared catalog and renderer files can be hardened. Splitting after RED would create cross-plan ownership of `src/cli/command-tree.ts` and `src/cli/render-human.ts` while still requiring the same integration test and gate summary; splitting before RED would permit production edits without the mandatory baseline. The path count is therefore not reduced artificially: each task changes at most five focused paths, no task spans another domain, and the preflight ordering remains mechanically enforceable.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Process argv → parser | Untrusted command tokens, option values, Unicode, and terminal controls enter the typed command tree. |
| Parsed command → dispatch | A valid later-phase path must stop at an unavailable result rather than cross into legacy handlers. |
| Structured outcome → stdout/stderr | Machine output must remain one uncontaminated document; human output must not execute terminal controls. |
