## Trust Boundaries

| Boundary | Description |
|---|---|
| Descriptor → process port | Fixed local tool identity crosses into host execution and must not become shell input. |
| Process output → result/report | Unbounded, partial, hostile, or interrupted output enters structured acceptance. |
| Baseline → integration descriptor | An in-suite baseline can recurse into the suite that is already running. |
| Result/report → stdout | Fixture/skip/failure can be hidden or human output can contaminate JSON. |
