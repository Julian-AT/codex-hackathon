## Trust Boundaries

| Boundary | Description |
|---|---|
| Catalog descriptor → host process | Fixed tool identity and arguments cross into actual Bun child-process execution. |
| Host process output/lifecycle → normalized result | Unbounded output, hangs, signals, and spawn failures can corrupt acceptance. |
| Process argv → validation entry | A caller may try to select arbitrary executables, arguments, or recursive package scripts. |
| Host facts → capability SKIP | Platform absence can be spoofed or missing implementation mislabeled as environmental absence. |
