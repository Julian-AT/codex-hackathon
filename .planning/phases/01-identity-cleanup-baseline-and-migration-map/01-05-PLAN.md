## Scope Justification

This plan owns 10 paths because canonical inventory validity, one-to-one reconciliation, computed eligibility, and the generated review are one fail-closed authority: splitting schema/scanner/gate from the exact JSON they validate would create a temporarily authoritative but unreconciled inventory, while splitting the pure three-file projection would create a duplicate prose window. Final cross-phase change ownership is excluded from this plan and assigned only to Plan 09 after all Phase 1 source/config work, reducing this execution context without weakening the inventory authority.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Repository/source paths → scanner | Tracked/untracked inputs can include sensitive ignored/operator paths or crafted locators. |
| Canonical JSON → removal eligibility | Tampered/stale declarations may attempt to authorize deletion. |
| JSON → Markdown/change review | A generated review can omit or misrepresent decisive evidence. |
