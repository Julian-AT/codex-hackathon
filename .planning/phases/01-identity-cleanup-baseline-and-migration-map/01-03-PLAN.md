## Scope Justification

This plan owns 11 paths because the state behavior crosses one intentionally narrow public leaf: resolver, ownership, init adapter, the sole command-tree option declaration, main wiring, and the pre-existing config seam each require their direct tests. Splitting the command-tree edit from init would recreate the checker-detected unreachable flag, while splitting config would permit a second Phase 1 root policy; each behavior remains behind focused modules and no Phase 2 storage work is introduced.
